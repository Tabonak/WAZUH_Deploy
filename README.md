1. Архитектура и ресурсы
Хост: Windows, 32 ГБ ОЗУ, ~1 ТБ диска, гипервизор VMware Workstation.
Виртуальные машины (4 шт):
- Windows Server 2022 (DC1) (6 ГБ ОЗУ, 60 ГБ диск) — Контроллер домена (DC).
- Windows 10 (arm1) (4 ГБ ОЗУ, 60 ГБ диск) — Клиент домена.
- Ubuntu Server 22.04 (8 ГБ ОЗУ, 100 ГБ диск) — Сервер Wazuh (SIEM).
- Ubuntu Desktop 22.04 (4 ГБ ОЗУ, 20 ГБ диск) — Клиент / Машина атакующего (пока не настроена до конца).

2. Настройка сети (VMware)
Для изоляции лабораторной сети был использован виртуальный коммутатор VMnet1 (Host-only).

В VMware для всех ВМ добавлен второй сетевой адаптер, подключенный к VMnet1. Первый адаптер оставлен как NAT (для выхода в интернет).
В обоих Windows машинах разрешено правило в Windows Defender для ICMP для проверки PING.

Распределение статических IP:
- Windows Server: 192.168.10.10 (DNS указывает на себя).
- Windows 10: 192.168.10.20 (DNS: 192.168.10.10).
- Ubuntu Server: 192.168.10.30.
- Ubuntu Desktop: 192.168.10.40.

3. Настройка Windows Server (Поднятие домена)
Установлен Windows Server 2022 Standard Evaluation (Desktop Experience) (180 дней, без ключа).
Установлены роли: AD DS (Active Directory Domain Services), DNS и DHCP.
Сервер повышен до контроллера домена. Создан новый лес и домен: lab.local.
В оснастке AD созданы тестовые пользователи (Mans).
В DHCP создана область для выдачи адресов клиентам (хотя клиенты пока используют статические IP).

4. Настройка Windows 10 (Клиент)
Машина введена в домен lab.local (использовались учетные данные администратора домена).
Проверен вход под доменной учетной записью Mans (через whoami).

5. Настройка Ubuntu Server (Wazuh)
Расширен виртуальный диск (с 10 ГБ до 100 ГБ) через VMware.
Внутри Ubuntu расширены разделы через LVM (команды growpart, pvresize, lvextend, resize2fs).
Настроен второй сетевой интерфейс (ens37) через Netplan (файл /etc/netplan/...yaml), ему присвоен IP 192.168.10.30.
Настроен файрвол (UFW): разрешен ICMP (ping) и порт 443 (для веб-интерфейса).
Установлен Wazuh (Manager + Indexer + Dashboard + Filebeat) скриптом wazuh-install.sh -a.
Получены логин (admin) и пароль для входа в веб-интерфейс Wazuh (https://192.168.10.30).
